# AI Support Assistant
An application where users describe an IT problem, and an AI assistant analyzes the issue and provides troubleshooting guidance.

## Features
- Issue Analysis: Understand the user's description of a technical problem
- Categorization: Identify whether the issue involves networking, hardware, software, access, etc.
- Troubleshooting: Provide step-by-step troubleshooting recommendations.
- Priority Assessment: Suggest a severity level.
- Conversation History: Keep track of previous questions and responses.
- Knowledge Base: Store common IT issues and solutions.
